# 🎄 Christmas Tree Lights

A tiny web game: press the button to turn the Christmas tree lights on and off.

**Play it:** https://twymanfamily.github.io/christmas-tree-lights/

Or open `index.html` in any web browser.

**On your phone:** open the [QR code page](https://twymanfamily.github.io/christmas-tree-lights/qr.html) on a computer and scan it.
